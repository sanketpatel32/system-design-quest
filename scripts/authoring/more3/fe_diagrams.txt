# Frontend 521-530 diagram specs. Integrator: append to scripts/diagrams/specs.txt, then run npm run diagrams.

@521 A strict Content Security Policy: the server sends a fresh nonce in the header and on its own script tags; the browser runs scripts carrying that nonce, blocks an injected script without it, and checks pinned files against their SRI hash.
Server [CSP header: nonce-R4nd0m]> Browser
Server [script tag with nonce-R4nd0m]> Browser [nonce matches]> Script runs
Injected script|no nonce > Browser [blocked, report sent]~> Report endpoint
CDN file > Browser [SHA-384 hash check]> Runs only if bytes match

@522 Web font loading: HTML, then CSS, then the font file is discovered late; a preload starts it with the CSS, and font-display swap shows fallback text at once and swaps in the web font when it arrives.
HTML > CSS|discovers @font-face [late start]> Font file
HTML [preload hint: early start]> Font file
Fallback text|shown at once [swap when loaded]> Web font text

@523 Client-side routing: a link click is intercepted, a new history entry is pushed and the view re-rendered without a page load; a refresh or deep link goes to the server, which must return the app shell for every app route.
Link click [intercept]> Router [push history entry]> New view|move focus, restore scroll
Back button [pop event]> Router [render previous view]> Old view
Refresh or deep link [GET /orders/42]> Server [app shell, not 404]> Router

@524 Formatting a message for a locale: the message pattern and the user's locale feed a plural rule and number and date formatters, producing different output for English, Hindi and Arabic, with layout mirrored for right-to-left scripts.
Message pattern|count, date > Plural rule|CLDR categories > Formatted text
Locale|en-IN, hi, ar > Number and date formats|12,34,567 > Formatted text
Locale|en-IN, hi, ar > Direction|ltr or rtl > Logical CSS|start and end

@525 Real-user monitoring: each sampled visit records metrics and errors, sends one beacon when the page is hidden, and the collector aggregates 75th and 95th percentiles by device, page and release.
Sampled visit|10% > Metrics and errors [beacon on page hide]~> Collector
Collector > Aggregate|p75, p95 by segment > Dashboard and alerts
Minified stack trace [private source map]> Readable error group

@526 Focus in a modal dialog: opening moves focus into the dialog, Tab cycles inside it while the page behind is inert, and closing returns focus to the button that opened it.
Open button [click: focus first control]> Dialog|page behind inert
Dialog|page behind inert [Tab cycles inside]> Dialog|page behind inert
Dialog|page behind inert [Escape: focus returned]> Open button
Status change [polite live region]~> Screen reader announcement

@527 A frontend test portfolio: many fast unit tests, a solid layer of component tests that query by role, and a few end-to-end tests of critical journeys; flaky tests go to quarantine with an owner.
Unit tests|many, milliseconds > Component tests|query by role > End-to-end|few critical journeys
Flaky test [quarantine with owner]~> Fixed or deleted

@528 How the cascade picks a winning declaration: origin and importance first, then the inline style attribute, then cascade layer, then specificity, then order of appearance; unlayered styles beat layered ones.
Competing declarations > Origin and importance > Inline style|beats selectors > Cascade layer|unlayered wins > Specificity|id, class, type > Order|last one wins

@529 Containing third-party scripts: a facade shows a lightweight preview image and loads the vendor widget only on click, while untrusted widgets run in a sandboxed cross-origin iframe with limited permissions.
Page [static facade]> Video preview [click]> Vendor player loads
Page [sandboxed iframe]> Ad or widget|own origin, limited rights
Vendor script [inventory with owner and budget]~> Review each quarter

@530 A request state machine: idle moves to loading on submit; loading moves to success or error; error can retry back to loading; submit is ignored while loading.
Idle [submit]> Loading [response ok]> Success
Loading [failure]> Error [retry]> Loading
Loading [submit again: ignored]~> Loading
